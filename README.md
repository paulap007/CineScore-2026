# CineScore - Streamlit

## Publicar en Streamlit Community Cloud
1. Descarga y descomprime este proyecto.
2. Crea una cuenta o inicia sesión en GitHub.
3. Crea un repositorio nuevo y sube `app.py` y `requirements.txt` (puedes subir también este README).
4. Entra a https://share.streamlit.io/ e inicia sesión con GitHub.
5. Selecciona **Create app** y el repositorio que creaste.
6. En el campo de archivo principal escribe `app.py`.
7. Pulsa **Deploy** y espera a que la app termine de instalar y arrancar.
8. Copia el enlace público que Streamlit te muestra y úsalo en tu tarea.

## Archivos
- `app.py`: aplicación CineScore.
- `requirements.txt`: dependencias.

La sección Comunidad registra las solicitudes solo durante la sesión actual; no utiliza una base de datos permanente.
